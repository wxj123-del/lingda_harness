# Agent Note: Configurable media generation plugins

Status: implemented

## Problem

The agent needs image and speech generation that can switch subscriptions and models without changing tool code. Images also need to appear in the existing conversation attachment renderer.

## Decision

The media generation core owns configuration validation, provider/model selection, per-call credentials, bounded HTTP, result download trust, cancellation, and provider usage retention. The image plugin owns OpenAI Images, compatible gateway, Volcano, DashScope/Wan, and Gemini adapters. It saves generated rasters through the existing attachment service and returns image and file blocks. The speech plugin owns OpenAI Speech, compatible gateway, DashScope, and Gemini adapters and returns a durable file attachment because the current session content vocabulary has no audio block.

Both plugins expose a model catalog tool. Empty configuration remains installable; selection fails with an actionable error until a valid route and credential exist. Provider selection never silently falls back when multiple routes match. Provider usage is retained as JSON; absent usage is null.

## Alternatives considered

Extending the existing `ContentBlock` vocabulary with an audio block would require coordinated session, transport, and client changes. Returning a durable file keeps the plugin compatible with the current attachment contract while preserving the generated bytes.

## Consequences

Configured endpoints and credential references are excluded from catalogs and tool results. Reference images can be local files or data URLs; local files are admitted through the current filesystem and attachment validators. Images render through the existing session-authorized gallery, and generated originals remain available as file attachments. Audio is downloadable through the existing file path.

## Validation

Focused provider, configuration, bounded transport, format, cancellation, and adapter tests pass. A real Loader composition drives one agent turn through both tools, checks durable image/audio bytes, checks credential rotation, and verifies tool disposal. The browser attachment plugin type-checks with a generated-image tool view.
