# Agent Note: 本地技能广场

Status: implemented

[English](2026-09-16-skill-marketplace.md) | 中文

## 问题

Skill 页面直接打开空编辑器，隐藏了模型已经能使用的两个内置创建技能。用户无法按用途浏览能力，也无法在不知道自动生成的运行时名称时选用 Skill。

## 决策

页面以本地目录展示内置和已保存的用户 Skill，提供来源筛选、持久化分类、搜索、指令详情和独立编辑器。“创建 Skill”与“创建工作流”的标识和本地化内容与 Host 注册共用。旧条目默认归入“通用”。分类仅用于界面展示，用户 Skill 的描述则包含标题以方便模型发现。

“用于对话”通过现有 Conversation 输入服务准备准确的斜杠调用，保留选中的会话及其草稿，必要时创建会话，不自动提交模型请求。布局导航 signal 防止延迟完成的会话创建覆盖后续导航。设置保存完成后才关闭编辑器，失败时保留草稿。

新增条目改为“上传 Skill”，不再打开空白创建表单。有限额的 ZIP 解析器识别唯一的 `SKILL.md`，校验 YAML 与调用权限，拒绝不安全或重复的路径。用户查看识别字段和资源列表后确认保存；同名上传会明确提示更新已有导入。原始压缩包保存在设置中，惰性 Skill 提供方在加载时重新验证，并按内容哈希解包到 Host 资源目录。导入不执行脚本。内置创建技能输出符合上传格式的指令。

## 考虑过的替代方案

**保留编辑器作为首屏。** 这会隐藏现有能力，也不符合浏览技能的用途。

**立即建设外部商城。** 托管、信任、发布和下载协议属于独立能力。本地目录能提供本次要求的初始体验，不需要虚构技能或安装数量。

## 影响

两个内置 Skill 无须安装即可使用，其指令生成可填入编辑器的内容，不自动保存条目。自建 Skill 可以编辑，停用条目不能选入对话。组件测试覆盖筛选、准确调用、停用状态和保存失败恢复；真实 Host 的浏览器场景覆盖分类持久化、响应式宽度及输入框草稿保留。

压缩包测试覆盖嵌套目录、二进制附件、调用权限、错误元数据、路径穿越与大小限制。浏览器测试验证上传、预览、持久化、资源加载和对话调用。限制为压缩后 2 MiB、解压后 8 MiB、最多 256 个条目，仅支持 ZIP 且每包一个 Skill。远程文件系统需要暴露 Host 资源目录才能使用附件。
