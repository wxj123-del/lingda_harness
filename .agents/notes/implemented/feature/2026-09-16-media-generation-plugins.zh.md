# Agent Note: 可配置媒体生成插件

Status: implemented

## 问题

智能体需要图片和语音生成能力，并且可以切换订阅套餐与模型而不修改工具代码。图片结果还需要复用现有对话附件渲染。

## 决策

媒体生成核心负责配置校验、Provider/模型选择、逐次解析密钥、有界 HTTP、安全结果下载、取消和 Provider 用量保留。图片插件负责 OpenAI Images、兼容网关、火山、DashScope/Wan 与 Gemini 适配器；它通过现有附件服务保存生成图片，并返回图片和文件块。语音插件负责 OpenAI Speech、兼容网关、DashScope 与 Gemini 适配器；由于当前会话内容词汇没有音频块，因此返回持久文件附件。

两个插件都提供模型目录工具。空配置仍可安装；在有效路由和密钥配置前，调用会给出明确错误。多个路由同时匹配时不会静默切换。Provider 未返回用量时保留为 null。

## 结果

模型目录和工具结果不会暴露端点或密钥引用。参考图支持本地文件和 data URL；本地文件通过现有文件系统与附件校验。图片通过现有会话授权图库展示，并同时保留原始文件附件。语音通过现有文件路径下载。

## 验证

Provider、配置、有界传输、格式、取消和适配器测试通过。真实 Loader 组合驱动一个智能体回合，验证持久化图片和音频字节、密钥轮换和工具卸载；客户端附件插件的生成图片视图通过类型检查。
