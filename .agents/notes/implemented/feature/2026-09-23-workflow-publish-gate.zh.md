# Agent Note：工作流发布门禁

状态：已实现

[English](2026-09-23-workflow-publish-gate.md) | 中文

## 问题

编辑器虽然已经展示草稿和已发布状态，但启用的草稿工作流仍会被注册成普通对话工具。即使目录页禁用了用户侧的对话按钮，模型仍然可能调用草稿。

## 决策

工作流工具注册现在要求工作流已启用且生命周期状态不是 `draft`。目录页的状态徽标和对话按钮使用同一个判断逻辑。没有生命周期字段的旧记录为保持兼容仍可运行；新建和导入的工作流会明确保持草稿，直到发布。编辑器的直接测试仍通过 Host Session 运行器可用。

## 结果

用户可以编辑和测试未完成的流程，而不会把未发布的图变成普通对话能力。发布成为模型/工具执行的唯一上线边界；禁用工作流仍会将其从工具注册表移除。

## 验证

工作流面板、布局加载和编译器测试通过。Client UI TypeScript、国际化校验以及 `git diff --check` 通过。
