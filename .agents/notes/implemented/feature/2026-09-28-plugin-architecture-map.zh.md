# Agent Note：插件架构图

状态：已实现

[English](2026-09-28-plugin-architecture-map.md) | 中文

## 问题

插件清单虽然提供了模块行和分类筛选，但没有展示已加载能力如何组合。用户需要先浏览卡片，才能理解当前组合的整体结构。

## 决策

插件清单页现在在详细卡片上方显示只读的拼图式能力架构图。架构图包含 Model、Skill、Tools、Session、Sandbox、Agent Loop、UI 和 Storage 八个稳定节点，使用本地化名称、现有基础图标、唯一模块数量和与参考图一致的版本标记。数量来自同一份宿主快照与当前选中的 Agent 预设。点击节点会复用现有分类筛选，不增加 Remote 数据，也不伪造运行时依赖图。

节点分类明确属于展示层启发式规则：宽泛分组复用现有分类器，Session、Sandbox、UI 和 Storage 使用明确的标识符关键词，因此自定义模块不需要改变宿主 payload 就能被发现。

## Alternatives considered

新增依赖图 Remote 会重复 Host 组合数据；用图完全替换可搜索清单又会让操作员失去精确模块行和筛选，因此均未采用。

## 结果

插件页在保留搜索和可展开清单的同时提供整体能力视图。当快照没有匹配模块时，概念节点可以显示 0；节点名称不表示这些模块之间存在直接运行时依赖。

## 验证

插件清单组件与浏览器插件测试通过（19 个测试）。包级 TypeScript 项目和客户端 bundle 构建通过。
