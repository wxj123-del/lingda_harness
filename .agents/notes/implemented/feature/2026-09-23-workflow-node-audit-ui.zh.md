# Agent Note: 工作流节点审计界面

Status: implemented

[English](2026-09-23-workflow-node-audit-ui.md) | 中文

## Problem

Host 已经提供节点级审计数据，但工作流编辑器的画布和历史运行视图还不能直观看到这些信息，也不能据此定位节点。

## Decision

编辑器会把当前选中运行记录中的最新审计条目映射到画布节点。运行中、已完成、失败、已跳过、依赖阻塞和已取消节点使用不同的视觉状态。选中节点后会显示有界的输入／输出摘要、耗时、错误和重试预算。运行详情中增加节点时间线，点击时间线条目可以定位对应画布节点。当依赖波次失败时，下游节点会收到明确的 `blocked` 终态记录，用于说明它们没有执行的原因。

## Alternatives considered

只显示运行级状态无法解释图的部分失败；暴露原始节点负载又会绕过 Host 的脱敏和大小边界，因此均未采用。

## Consequences

实时运行和从持久化历史加载的运行使用同一套审计展示。没有审计数据的旧运行仍可正常显示。审计摘要继续沿用 Host 侧的脱敏和大小限制，界面只读展示。

## Verification

工作流面板测试覆盖状态映射、历史审计加载、节点定位、摘要、耗时和重试展示。相关 Workflow、Session Controller 和 UI 测试套件均通过。
