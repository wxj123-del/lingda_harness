# Agent Note: 节省 Token 的 Agent 预设

Status: implemented

[English](2026-09-16-diaosi-agent-preset.md) | 中文

## Problem

宽泛搜索和反复整文件读取会累积工具输出，后续模型请求不断重发这些内容。用户需要一个可选的日常模式来限制增长，同时保留自选模型、文件编辑和 Skills。

## Decision

随附的 `diaosi` preset 在中文界面显示为「屌丝模式」，英文界面显示为 Budget mode。它组装现有的作用域工具和输出策略，不添加全局优化器。人设要求定向搜索、分段读取，并复用仍在上下文中的未改动片段。项目指令、宿主权限、沙箱和模型路由保持现有归属。

[预设组装](../../../../packages/preset/agent-presets/presets/diaosi/agent.cordis.yml)直接配置文件读取与搜索限制，因为通用 spill 处理跳过 `read`。其作用域 spill 策略通过共享后端，将 Shell、搜索、网页及任务输出文本限制为含取回指引的 8,000 字节。作用域策略先于宿主限制作出处理，使保存的产物包含原始格式化结果。私有压缩组先修剪旧结果再生成摘要，并相对于所选模型的上下文窗口更早触发。宿主 Token 计量器与 spill 后端仍是共享的进程级基础设施。

缩短后的人设鼓励直接回答简单问题，简洁回复，避免重复日志或计划。这些是模型指令，并非输出硬上限。精简 Skill 目录缩短指引，同时保留名称、描述、加载规则和完整指令正文。未变的目录不会仅因样式变更而重新发布，既有历史保持完整。项目与权限指令不作精简。

作用域内的[工具发现插件](../../../../packages/preset/tool-discovery/README.zh.md)初始提供四个工具与搜索入口，依据历史实际调用次数排序，每次搜索最多加载两个相关工具。该筛选也覆盖继承的宿主媒体 schema。选择最多保留八个工具与搜索入口，并从现有请求头和已提交结果元数据恢复；循环与执行权限保持不变。完整名称只加载一个工具，无匹配查询不会倾倒完整目录。

## Alternatives considered

**仅添加提示词预设。** 指令无法强制限制输出，因此同时设置工具自身的上限。

**全局优化插件。** 它会影响其他预设，且需要新增路由或去重行为。现有组装系统可以用更少机制提供明确的逐会话选择。

**自动更换所选模型。** 提供方价格与能力属于用户选择，预设保留已配置的路由。

## Consequences

本预设不加载委派、工作流、目标和计划模式插件。需要未注册能力的任务应在新会话中使用其他预设。输出限制可能增加分页读取次数，提前生成摘要也会消耗 Token、丢失细节。工具发现可能增加一轮模型请求，schema 改变时也可能使缓存前缀失效。本模式不提供固定的总 Token 上限、自动重复读取缓存或经过测量的计费节省百分比。必要验证仍优先于减少输出。

单元测试覆盖发现与双语名称。真实 Web 组装测试验证所选模型身份、作用域读取、搜索限制、通用 spill 预览与压缩器隔离，并记录人设快照。浏览器测试记录选择器并验证刷新后保留选择。这些无密钥检查不测量依赖提供方的压缩质量和端到端 Token 节省。

无密钥的 `skill-compact` 会话快照通过随附 headless profile 固定精简目录文本与完整 Skill 加载。Web 请求检查比较两种目录样式，并保留项目和权限上下文。作用域 spill 测试验证全文保存、宿主挂载顺序与卸载；标准会话保留宿主上限。

工具选择测试覆盖频次排序、作用域执行拒绝、有界搜索、仅提交后激活、释放、取消和日志恢复。真实 Loader/Web 组装通过脚本模型执行搜索和媒体调用，对照实际请求检查已记录的请求头，并快照记录目录变化与工具结果。图片测试工具不会调用图片提供方。
