# Agent Note：共享可视化工作流图校验

Status: implemented

[English](2026-09-23-workflow-graph-validation.md) | 中文

## Problem

可视化编辑器和编译器此前各自校验同一张图。尤其在 HTTP 配置、凭据、重试次数、标识、重复连线和图可达性方面，可能出现编辑器认为有效、运行时却无法编译的情况。

## Decision

新增共享的 `analyzeWorkflowGraph()`，同时负责结构校验和图索引构建。编辑器把稳定的 issue code 映射为本地化提示，编译器则在发现任何问题时拒绝编译，并使用同一套邻接索引和拓扑顺序。校验覆盖节点与连线数量上限、标识、节点必要配置、HTTP 方法与 URL、凭据引用、重试范围、起止节点数量、连线引用、重复连线、分支句柄、可达性、死路、条件分支重复和循环。

## Alternatives considered

分别维护编辑器和编译器校验器会导致契约漂移；把校验延迟到执行阶段则可能先产生模型、工具或 HTTP 副作用，因此均未采用。

## Consequences

发布和直接测试运行现在使用与编译器完全一致的图契约。无效或有歧义的图会在任何模型、工具或 HTTP 副作用开始前失败。校验通过后，编译器仍使用原有的依赖波次执行策略。

## Validation

共享校验测试覆盖有效图、严格的 HTTP／凭据／重试／标识校验、重复连线、循环和断开节点。UI Layout 测试与 TypeScript 检查通过。
