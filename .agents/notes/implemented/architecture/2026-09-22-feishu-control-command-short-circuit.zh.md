# Agent Note：飞书控制命令短路

[English](2026-09-22-feishu-control-command-short-circuit.md) | 中文

状态：已实现

## 问题

飞书适配器此前会把斜杠命令送入普通 Agent 追问路径。模式切换、压缩和其他人工控制因此可能变成模型可见的用户消息，并意外启动模型轮次。

## 决策

飞书适配器在排队普通 Agent 追问之前解析已注册的斜杠命令。这样模式切换、压缩和其他人工命令不会进入模型循环。未知斜杠命令会以接纳错误结束，只有非命令文本才会成为模型可见的飞书用户消息。一个小型解析器还会把无歧义的中文模式短语映射到已有的 `/mode` 命令。

## 曾考虑的替代方案

**把所有消息转发给 Agent。** 否决，因为控制命令会和模型输入竞争，并可能在人类操作完成前触发工作。

**把未知斜杠命令当作普通文本。** 否决，因为控制命令拼写错误应返回接纳错误，而不是静默地让模型解释。

## 影响

已注册的飞书控制命令现在会在模型追问前完成，只有普通文本会记录为模型可见的用户消息。解析器仍属于适配器本身，并复用已有的 `/mode` 命令词汇。
