# Agent Note: 极简 preset 包含配置的模型身份

Status: implemented

[English](2026-09-15-minimal-preset-model-identity.md) | 中文

## 问题

Web `minimal` preset 用通用软件助手人设替换整个系统提示词，并抑制运行时上下文。模型没有收到配置的模型身份，因此回答身份问题时可能使用无关的模型或厂商名称。

## 决策

完整人设通过现有系统提示词变量，从当前 agent 选项插入 `{{model}}` 和 `{{provider}}`。它描述配置的路由，包括自定义提供方和模型标识，不断言用户配置的端点背后的厂商。该 preset 仍仅提供一个持久 shell，并抑制其他提示词段落和运行时上下文。

本决策部分取代[极简裸运行时决策](../feature/2026-08-11-minimal-profiles-bare-two-tool-runtime.zh.md)中的固定 Web 人设。原决策继续负责运行时上下文抑制和独立 SDK 配置。

## 考虑过的替代方案

**将模型硬编码为 DeepSeek。** 不予采用，因为用户可以选择其他提供方或模型。

**恢复全局提示词和运行时上下文。** 不予采用，因为现有变量可以提供缺失的身份信息，无需重新引入无关指令。

## 验证

Web 组合测试使用 DeepSeek 和自定义路由渲染随附极简人设。Web minimal-preset 录制回放在记录的系统提示词中固定渲染后的身份，并检查其他段落和运行时上下文消息仍未出现。

## 后果

身份信息为提示词增加一个简短分句。它反映配置的请求路由，无法验证远端实际提供的模型，也无法保证模型生成的回答。现有用户自建副本需要进行同样的模板更新。
