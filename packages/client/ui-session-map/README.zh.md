# @deepseek-ai/dsh-client-ui-session-map

[English](README.md) | 中文

## 概述

**地图**标签把当前会话画成一条竖直线上的回合主线。每个已完成的回合是一张卡片，带提示词与最终回复的有界预览；从该回合分出的每个会话都以分支 chip 的形式紧贴在它下面。卡片上的**从这里分叉**会在该回合处复制对话，因此探索另一种走向不需要再回到对话记录里找同一个位置。

<a id="use-this-package"></a>
## 使用本包

在会话的视图切换栏里打开**地图**标签。头部写明地图包含多少回合与分支；下方主线按回合号升序列出全部回合。

每张卡片显示回合编号、提示词预览与最终回复预览。提示词预览为空时（只有模型发言的回合，或首条消息不带文本的回合）卡片会明确说明，而不是留一行空白。

### 分叉

**从这里分叉**会在该回合之后立即分叉对话。它用的是聊天里回合操作所用的同一个 Session Controller 动词（`fork({ atSeq, increaseTitle: true })`），因此从地图创建的分支与从聊天创建的分支行为完全一致：继承源会话前缀、标题递增、挂到同一个 Workspace，并在被打开之前保持关闭。会话运行期间禁止分叉；一次分叉进行中时，所有卡片的按钮都会禁用。分叉失败会在主线之上说明原因，按钮仍可重试。

### 分支

分支 chip 显示子会话标题、它包含的回合数，以及运行中的标记。点击 chip 会打开该会话，整个对话界面（包括本标签的内容）切换到该分支。地图始终描述当前显示在屏幕上的那个会话。

自身回合大纲不可用的分支无法对应到某一轮，会被列在单独一节里并说明原因，而不是被猜测着挂到最近的某一行。子代理来源的子会话不会作为分支出现，与浏览器列表保持一致。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

`buildSessionMap`（`src/client/map.ts`）是纯函数，只处理线数据。它按聊天回合轨同样的一套容错规则收窄 `turnOutline` 投影——`turn` 或 `seq` 不可用的条目直接丢弃，预览降级为空字符串——然后用**继承回合数**定位子会话：分叉复制源会话前缀，因此子会话大纲的长度正好是它在父会话中分出时的那一轮。自身没有大纲的子会话会被报告为未定位。

视图只读三个框架数据源：`useSession` 提供运行期的分叉门禁、`useProjection('turnOutline')` 提供主线、`useSessions` 提供分叉谱系（`parentId` 加上每个子会话的大纲长度）。它不发起任何 Host 请求，也不持有持久状态；唯一的本地状态是进行中的分叉标记和最近一次错误。

</details>

<a id="model-experience"></a>
## 模型体验

无，本包是纯浏览器侧 UI 插件层，不注册任何面向模型的能力。

#### KV Cache 影响

无；本包既不组装也不发送任何 provider 请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **没有画布布局** —— 地图是一条竖直线，而不是自由布局的图形。分支 chip 缩进在来源回合之下，没有平移、缩放、拖拽，也不按会话持久化布局。
- **只显示直接分叉** —— 分支的分支要在该分支成为当前会话时才出现；地图不会一次遍历整棵树。
- **分叉定位依赖投影数据** —— 刚在本进程中创建、大纲尚未投影出来的分支会先列为未定位，等摘要刷新后才归位。
- **依赖视图切换栏** —— 在设置里关闭「显示会话视图切换栏」后，所有视图标签（包括本标签）都不渲染。

<a id="dev-note"></a>
### 开发者注记

<details>
<summary>维护者工作背景——点击展开</summary>

地图刻意不自建分叉逻辑：`forkAt` 走的是聊天回合操作所用的同一个列表服务。共用同一个分叉动词，两个入口在继承内容与子会话命名上就不会走偏。

</details>

**运行时不变式：** 不发布伴随模块。本包注册一个会话视图条目及其字典；它不提供服务，也不持有跨插件的可变状态。
